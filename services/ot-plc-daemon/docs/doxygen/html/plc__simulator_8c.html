Detailed Description

Simulation physique du four de trempe (EN 12150) : chauffe 4 zones, trempe, casse thermique.

Aucune allocation dynamique. plc_simulator_step() prend le verrou du contexte ; plc_apply_command(), plc_trigger_estop() et plc_reset_estop() exigent qu'il soit détenu.
